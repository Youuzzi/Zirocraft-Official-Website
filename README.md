# Zirocraft Official Website

The official corporate website of **Zirocraft**, a technology company focused on building practical technology solutions for growing businesses.

This repository contains the source code for the Zirocraft corporate website, including company information and product-related content.

## Featured Product

### ZiroPOS

**ZiroPOS** is Zirocraft's Business Management & Point of Sale Platform.

The website serves as the primary public-facing destination for introducing ZiroPOS, communicating its positioning, and providing information about the product.

## Technology Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- ESLint

## Getting Started

### Requirements

- Node.js 20 or later
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/Youuzzi/Zirocraft-Official-Website.git
cd Zirocraft-Official-Website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

| Command         | Description              |
| --------------- | ------------------------ |
| `npm run dev`   | Start development server |
| `npm run lint`  | Run ESLint               |
| `npm run build` | Create production build  |
| `npm run start` | Start production server  |
